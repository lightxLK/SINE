This dataset contains 1000 e-commerce product reviews collected from simulated users across three major online platforms: Amazon, Flipkart, and Myntra. Each review is labeled with its sentiment polarity — Positive, Neutral, or Negative — making it suitable for sentiment analysis, text classification, and natural language processing (NLP) tasks.

Purpose: To provide a labeled dataset for training and testing machine learning models in sentiment analysis.

Columns:
Text → The review content provided by the user.
Label → The sentiment category (Positive, Neutral, Negative).
Window → The e-commerce platform (Amazon, Flipkart, Myntra).
User Name → The reviewer’s (simulated) first name.
User ID → A unique identifier assigned to each reviewer.

Size: 1000 rows, 5 columns.

Applications:
Sentiment analysis
Text classification
E-commerce product review analysis
Training NLP models

1. INTRODUCTION

In today’s digital era, online shopping platforms such as Amazon, Flipkart, and others rely heavily on customer reviews to influence purchasing decisions. These reviews provide valuable insights into customer satisfaction, product quality, and service performance.

However, analyzing thousands of reviews manually is inefficient and time-consuming. This is where Sentiment Analysis comes into play. Sentiment Analysis is a Natural Language Processing (NLP) technique used to determine whether a piece of text expresses positive, negative, or neutral sentiment.

This project aims to build a machine learning-based system that automatically analyzes customer reviews and predicts their sentiment.

--------------------------------------------------

2. OBJECTIVE / AIM

The main objectives of this project are:

- To analyze textual product reviews using NLP techniques
- To classify reviews into Positive, Negative, or Neutral categories
- To convert textual data into numerical features using TF-IDF or embeddings
- To apply machine learning models for sentiment classification
- To evaluate model performance using standard metrics
- To provide insights into customer opinions

--------------------------------------------------

3. PROBLEM STATEMENT

E-commerce platforms receive a massive amount of customer feedback daily. Manually analyzing these reviews is not feasible. Businesses require an automated system that can:

- Process large volumes of text data
- Understand customer sentiment

This project addresses the problem by building an automated sentiment analysis system using NLP and machine learning techniques.

8. METHODOLOGY

The project follows these steps:

8.1 Data Collection:
- Collect dataset from Kaggle or other sources

8.2 Data Preprocessing:
- Convert text to lowercase
- Remove punctuation and special characters
- Remove stopwords
- Tokenization
- Lemmatization/Stemming

8.3 Feature Extraction:
- Convert text into numerical form using:
  - TF-IDF (Term Frequency-Inverse Document Frequency)
  OR
  - Word Embeddings (Word2Vec, GloVe)

8.4 Model Building:
- Train classification models such as:
  - Naive Bayes
  - Logistic Regression
  - Support Vector Machine (optional)

8.5 Model Evaluation:
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

8.6 Prediction:
- Input new review → Output sentiment
